# Laboratorio 3: Aplicaciones web vulnerables

## Objetivo

Practicar vulnerabilidades web en entornos controlados.

## Aplicaciones incluidas

### DVWA
- SQL Injection
- XSS
- CSRF
- File Inclusion
- Command Injection

### OWASP Juice Shop
- Broken access control
- Authentication flaws
- Insecure deserialization patterns
- JWT issues
- XSS and challenge flows

## Ejercicios sugeridos

1. Abre DVWA en `http://localhost:8081`.
2. Cambia los niveles de seguridad y observa el impacto.
3. Identifica rutas y parámetros útiles para pruebas.
4. En Juice Shop, intenta resolver retos del nivel básico al intermedio.
5. Documenta cada hallazgo y la corrección recomendada.

## Consejos

- Usa un navegador con herramientas de desarrollo.
- Inspecciona parámetros, cookies y cabeceras.
- Revisa el código HTML y JS de las páginas para encontrar endpoints y lógica frágil.
