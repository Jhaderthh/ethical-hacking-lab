# Herramientas recomendadas

Estas herramientas son útiles para practicar y reforzar conceptos de seguridad ofensiva.

## Reconocimiento y escaneo
- Nmap
- Netdiscover
- Whois
- Dig
- Ping
- Masscan

## Web y aplicaciones
- Burp Suite Community
- OWASP ZAP
- sqlmap
- Gobuster
- Nikto

## Explotación y análisis
- Metasploit Framework
- Searchsploit
- John the Ripper
- Wireshark
- Hydra

## Entornos de laboratorio
- DVWA
- OWASP Juice Shop
- WebGoat
- Metasploitable
- Damn Vulnerable Ranch

## Consejo

No intentes usar todas a la vez. Empieza con una pequeña ruta de aprendizaje: reconocimiento, escaneo, web, explotación y remediación.
