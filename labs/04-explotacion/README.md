# Laboratorio 4: Explotación y remediación

## Objetivo

Entender cómo una vulnerabilidad puede explotarse y cómo mitigarla.

## Conceptos clave

- Exfiltración de datos
- Elevación de privilegios
- Spoofing y manipulación de sesiones
- Inyección
- Fuzzing básico

## Ejercicios sugeridos

1. Identifica una vulnerabilidad en una aplicación del laboratorio.
2. Reproduce el comportamiento usando una prueba controlada.
3. Documenta: causa, impacto y propuesta de mitigación.
4. Casos de estudio: SQLi, XSS, IDOR, command injection.

## Buenas prácticas

- No ejecutes payloads destructivos.
- Limita cada prueba a un escenario autorizado.
- Haz una recolección de evidencia mínima.
- Siempre concluye con una recomendación técnica.
